Screens

Every screen of the game, drawn with the game's own code on made-up but realistic games (late endless waves, big numbers, every perk), so text that doesn't fit shows up at a glance. Edit src/render.js and reload. ?only=pause shows just the screens whose name contains that word; ?size=1500x656 draws them as a window of that shape shows them (the base is 1008x656).
